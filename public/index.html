สำรองข้อมูล (JSON Backup)

ส่งออกข้อมูลแผงโซลาร์ทั้งหมด รวมถึงประวัติพิกัด GPS, Inverter, String และสถานะล่าสุดในรูปแบบไฟล์ JSON มาตรฐาน

นำเข้าข้อมูล (Import Panels)

นำเข้าข้อมูลจากไฟล์ JSON หรือ Backup เดิม

เลือกไฟล์ JSON ที่มีโครงสร้างข้อมูลแผงโซลาร์ ระบบจะทำการ Upsert ข้อมูลลงฐานข้อมูลโดยอัตโนมัติ

เติมชุดข้อมูลทดสอบ (Demo Seed)

สร้างแผง Longi, Jinko, Trina จำลอง

ระบบจะสร้างตัวอย่างแผงโซลาร์ 12 แผง พร้อมผูก Inverter, String, ค่าวัตต์, พิกัด GPS และสถานะต่างๆ เพื่อความสะดวกในการทดสอบระบบ
