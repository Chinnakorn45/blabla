# SolarTrack - ระบบบันทึกและติดตามซีเรียลแผงโซลาร์เซลล์ (Solar Panel Tracking System)

เว็บแอปพลิเคชันสำหรับงานภาคสนาม (Field Operations) ออกแบบมาเพื่อทีมช่างและวิศวกรโซลาร์เซลล์โดยเฉพาะ สำหรับใช้สแกนบาร์โค้ด/QR Code ประจำแผงด้วยกล้องโทรศัพท์มือถือ บันทึกการรับเข้าคลังสินค้า และการติดตั้งเข้ากับ Inverter/String หน้างานแบบต่อเนื่อง

## ⚡ เทคโนโลยีที่เลือกใช้ (Tech Stack)

1. **Frontend**:
   - **HTML5 & Vanilla JavaScript**: น้ำหนักเบา โหลดไว ไม่ต้องติดตั้ง Build Tool เหมาะกับงานภาคสนามที่สัญญาณอินเทอร์เน็ตอาจไม่เสถียร
   - **Tailwind CSS (compiled locally)**: ออกแบบ UI แบบ Mobile-First รองรับการสัมผัสด้วยนิ้วมือ (Touch Targets $\ge$ 48px) พร้อมสีคอนทราสต์ชัดเจนเมื่อทำงานกลางแดด
   - **html5-qrcode Library (self-hosted)**: ไลบรารีสแกนบาร์โค้ด 1D (Code 128, Code 39) และ 2D (QR Code, Data Matrix) ผ่านกล้องมือถือ
   - **Lucide Icons (self-hosted)**: ไอคอนสไตล์ Modern เรียบง่าย สื่อความหมายชัดเจน
   - **Web Audio API & Vibration API**: สร้างเสียง Beep และการสั่นแจ้งเตือนทันทีที่สแกนติดโดยไม่ต้องดาวน์โหลดไฟล์เสียงภายนอก

2. **Backend**:
   - **Node.js + Express**: RESTful API ประสิทธิภาพสูง รองรับ JSON Body, CORS และการ Serve Static Files
   - **SQLite (`sqlite3`)**: ฐานข้อมูลไฟล์เดี่ยว (`solar_panels.db`) น้ำหนักเบา ไม่ต้องติดตั้ง Database Server แยก พร้อมระบบ Auto-Fallback สลับไปใช้ Local Storage / JSON Store ทันทีหากไม่ได้ติดตั้ง Driver SQLite

## 📱 User Flow ทั้ง 4 หน้าจอหลัก

1. **หน้าจอหลัก (Dashboard)**:
   - ปุ่มหลักสำหรับภาคสนาม: **"สแกนรับเข้าคลัง"**, **"เบิกแผงไปหน้างาน"** และ **"เบิกอุปกรณ์หน้างาน"**
   - การ์ดสรุปยอด: รวมทั้งหมด, ในคลัง, กำลังติดตั้ง, ติดตั้งแล้วเสร็จ และจำนวนโครงการ
   - ตารางรายการบันทึกล่าสุด พร้อมช่องค้นหาด่วน (Search), กรองตามโครงการ และกรองตามสถานะ
   - ปุ่ม Export ข้อมูลเป็น Excel/CSV (พร้อม UTF-8 BOM รองรับภาษาไทย 100%)

2. **หน้าจอสแกนบาร์โค้ด (Scanner View)**:
   - หน้าจอกล้องเต็มเฟรม พร้อมเส้นเลเซอร์แอนิเมชันสีแดงและกรอบมุม 4 ทิศ
   - ปุ่มเปิด/ปิดไฟฉาย (Torch) สำหรับสแกนใต้โครงสร้างหลังคาหรือช่วงแสงน้อย
   - ปุ่มสลับกล้อง (หน้า/หลัง)
   - ปุ่มกรอกรหัสด้วยมือ (Manual Input) กรณีบาร์โค้ดเปียกฝนหรือชำรุด
   - เสียง Beep และการสั่นเตือนทันทีที่ตรวจพบบาร์โค้ด

3. **หน้าจอบันทึกข้อมูล (Data Form)**:
   - ดึงรหัส Serial Number ที่สแกนได้มาแสดงอัตโนมัติ
   - **ตรวจสอบ Serial Number ก่อนเบิก**: เบิกไปหน้างานได้เฉพาะแผงที่มีสถานะอยู่ในคลัง หาก SN ถูกเบิกแล้วจะแสดงโครงการและสถานะเดิม (เช่น ชำรุด/เคลม) และป้องกันการเบิกซ้ำ
   - ช่องระบุ: ชื่อโครงการ, Inverter, String, ลำดับแผงใน String, ยี่ห้อ/รุ่น, ขนาดวัตต์, ชื่อช่าง
   - **ปุ่มดึงพิกัด GPS อัตโนมัติ (Geolocation API)**: บันทึก Latitude/Longitude ของจุดติดตั้งจริง
   - ปุ่มเลือกสถานะแบบ Pill Cards ขนาดใหญ่

4. **หน้าจอแสดงผลสำเร็จ (Success State)**:
   - สรุปรายละเอียดแผงที่เพิ่งบันทึกเสร็จสมบูรณ์
   - ปุ่ม **"สแกนแผงถัดไป (Scan Next)"**: ออกแบบสำหรับงานติดตั้ง String ต่อเนื่อง (ระบบจะจดจำโครงการ, Inverter, String เดิมไว้ และเพิ่มลำดับแผงให้อัตโนมัติ ช่วยลดเวลาหน้างานได้กว่า 80%)

### ขั้นตอนการเคลื่อนย้ายแผง

1. ก่อนรับเข้า ให้เลือกรุ่นหรือยี่ห้อแผง แล้วสแกน/ระบุ SN เพื่อเพิ่มแผงในสต๊อก
3. เมื่อจ่ายแผง ให้เลือกโครงการปลายทางและสแกน SN ในโหมดหน้างาน ระบบจะเปลี่ยนสถานะจากคลังเป็นสถานะหน้างานและตัดออกจากยอดสต๊อก
4. คลังกลางเป็นตำแหน่งสต๊อก ไม่ใช่โครงการ จึงไม่รวมในรายชื่อและจำนวนโครงการ
5. ค้นหา/สแกน SN ที่หน้างานเพื่อตรวจสอบโครงการและสถานะปัจจุบันได้ โดย SN ที่ถูกเบิกแล้วจะไม่สามารถเบิกซ้ำได้
6. ส่งออก Excel จากการ์ดโครงการ เพื่อดูสรุปรุ่นแผง จำนวน และ SN พร้อมข้อมูล Inverter / String

ฐานข้อมูลใหม่เริ่มต้นว่าง ไม่มีข้อมูลตัวอย่างถูกเติมอัตโนมัติระหว่าง deploy; ใช้ปุ่มเพิ่มข้อมูลตัวอย่างในหน้าจัดการฐานข้อมูลเมื่อต้องการทดสอบเท่านั้น

### การเบิกอุปกรณ์ไปหน้างาน

ในเมนู **จัดการฐานข้อมูล → เบิกอุปกรณ์หน้างาน** สามารถเพิ่มทะเบียนอุปกรณ์พร้อมหน่วยนับ แล้วบันทึกประวัติการเบิกแยกตามโครงการ วันที่ ผู้เบิก และจำนวนอุปกรณ์ได้ ประวัติแก้ไขหรือลบได้ โดยการลบอุปกรณ์ออกจากทะเบียนจะไม่ลบชื่ออุปกรณ์ในประวัติเดิม ฟังก์ชันนี้เป็นการเก็บประวัติ ไม่ได้ควบคุมยอดรับเข้า/ยอดคงเหลือ

## 🚀 วิธีการติดตั้งและรันโปรเจกต์ (Step-by-Step Guide)

### ขั้นตอนที่ 1: ติดตั้ง Node.js
ตรวจสอบว่าเครื่องคอมพิวเตอร์ของคุณมี Node.js (แนะนำเวอร์ชัน 16 หรือใหม่กว่า)
```bash
node -v
npm -v
```

### ขั้นตอนที่ 2: เปิดแอปผ่านเซิร์ฟเวอร์
ติดตั้ง dependency และเริ่มเซิร์ฟเวอร์จากโฟลเดอร์โปรเจกต์:
```bash
npm install
npm start
```
จากนั้นเปิด `http://localhost:3000` อย่าเปิด `public/index.html` ด้วย `file://` โดยตรง เพราะเบราว์เซอร์จะปฏิเสธคำขอ API และใช้ฐานข้อมูลโครงการไม่ได้

ไฟล์ไอคอนและตัวสแกนถูกเสิร์ฟจาก dependency ภายในโปรเจกต์ และใช้ฟอนต์ระบบ จึงไม่ต้องพึ่ง CDN ภายนอก

### ขั้นตอนที่ 2: ติดตั้ง Dependencies
เปิด Terminal หรือ PowerShell ในโฟลเดอร์ของโปรเจกต์ (`c:\blabla`) แล้วสั่ง:
```bash
npm install
```
*(ระบบจะดาวน์โหลด `express`, `cors` และ `sqlite3`)*

### ขั้นตอนที่ 3: สตาร์ทเซิร์ฟเวอร์
```bash
npm start
```
หรือหากต้องการเปิดโหมด Auto-reload สำหรับ Developer:
```bash
npm run dev
```

เมื่อเซิร์ฟเวอร์เริ่มทำงาน จะแสดงข้อความใน Terminal ดังนี้:
```text
====================================================
☀️  SOLAR PANEL TRACKING SYSTEM (FIELD OPS) READY
====================================================
💻 Local:   http://localhost:3000
📱 Mobile (Same Wi-Fi network):
   ➜ http://192.168.1.XX:3000
----------------------------------------------------
```

## 📲 วิธีทดสอบการเปิดกล้องผ่านโทรศัพท์มือถือ (Important Note)

เบราว์เซอร์มือถือสมัยใหม่ (ทั้ง Google Chrome บน Android และ Safari บน iOS) มีนโยบายความปลอดภัยที่เข้มงวด: **จะอนุญาตให้เว็บเข้าถึงกล้องได้เฉพาะเมื่อรันบน `localhost` หรือเชื่อมต่อผ่าน `HTTPS` เท่านั้น**

เลือกใช้วิธีใดวิธีหนึ่งด้านล่างนี้เมื่อต้องการทดสอบด้วยมือถือจริง:

### ทางเลือก A: ใช้ ngrok สร้าง HTTPS URL ฟรีและเร็วที่สุด (แนะนำ)
1. ติดตั้ง ngrok หรือเปิดเทอร์มินัลแล้วสั่ง:
   ```bash
   npx ngrok http 3000
   ```
2. คุณจะได้ URL ที่ขึ้นต้นด้วย `https://xxxx.ngrok-free.app`
3. เปิด URL ดังกล่าวบนโทรศัพท์มือถือ จะสามารถเปิดกล้องสแกนและเปิดไฟฉายได้ทันที!

### ทางเลือก B: เปิดผ่าน Chrome Flag บน Android
หากเชื่อมต่อ Wi-Fi วงเดียวกันกับคอมพิวเตอร์:
1. เปิดแอป Chrome บนมือถือ แล้วเข้าไปที่ URL:
   ```text
   chrome://flags/#unsafely-treat-insecure-origin-as-secure
   ```
2. ใส่ IP เครื่องคอมพิวเตอร์ของคุณ เช่น `http://192.168.1.50:3000`
3. เลือกเป็น **Enabled** แล้วกด **Relaunch** มือถือจะอนุญาตให้เปิดกล้องได้ทันที

### ทางเลือก C: ทดสอบแบบ Standalone บนคอมพิวเตอร์
เปิดไฟล์ `public/index.html` บนเบราว์เซอร์ในคอมพิวเตอร์ได้โดยตรง (เว็บจะเปิดกล้องเว็บแคม หรือใช้ปุ่ม "กรอกรหัสด้วยมือ" เพื่อทดสอบโฟลว์งานได้ทันที แม้ไม่มีเซิร์ฟเวอร์)

## 📡 สรุป REST API Endpoints

| Method | Endpoint | รายละเอียด |
|---|---|---|
| `GET` | `/api/health` | ตรวจสอบสถานะเซิร์ฟเวอร์ |
| `GET` | `/api/stats` | สรุปยอดจำนวนแผงแยกตามสถานะ และจำนวนโครงการ |
| `GET` | `/api/panels` | รายการแผงโซลาร์ (รองรับ query params: `search`, `project`, `status`, `limit`) |
| `GET` | `/api/panels/:serial` | ตรวจสอบข้อมูลแผงจาก Serial Number (ใช้ตรวจข้อมูลซ้ำ) |
| `POST` | `/api/panels` | บันทึกข้อมูลแผงใหม่ หรืออัปเดตข้อมูลแผงเดิม |
| `DELETE`| `/api/panels/:id` | ลบข้อมูลแผงโซลาร์ |
| `GET` | `/api/projects` | รายชื่อโครงการทั้งหมดในระบบ |
| `GET/POST` | `/api/equipment` | ดูหรือเพิ่มทะเบียนอุปกรณ์ |
| `PUT/DELETE` | `/api/equipment/:id` | แก้ไขหรือลบอุปกรณ์จากทะเบียน |
| `GET/POST` | `/api/equipment/issues` | ดูประวัติหรือบันทึกการเบิกอุปกรณ์ |
| `PUT/DELETE` | `/api/equipment/issues/:id` | แก้ไขหรือลบประวัติการเบิก |
| `GET` | `/api/export/csv` | ส่งออกข้อมูลเป็นไฟล์ Excel CSV พร้อมภาษาไทย |
